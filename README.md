# Lesson 30 — The Oldest Living Culture on Earth 🪃

Playful-Detective teaching pack for a one-hour online English lesson (Grade 4/5):
an information text about the Aboriginal peoples of Australia, then **simple, compound and complex sentences**.

**Open `index.html`** — or publish this folder with GitHub Pages and it works as a website.

| File | What it is |
| --- | --- |
| `index.html` | Landing page linking the lesson and both games |
| `lesson-30-aboriginal-australia.html` | The 20-slide lesson (arrow keys, thumbnail rail, ⛶ Present, print to PDF) |
| `outback-connect-4.html` | Connect 4 against the Kangaroo |
| `outback-word-search.html` | Outback word search (14 words, hints + timer) |

## Publishing on GitHub Pages

1. Push the contents of this folder to a repository (root, or a `docs/` folder).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` or `/docs`.
3. Open the published URL. `index.html` is the home page.

Everything is static and uses **relative paths only** — no build step and no server code.

## Folders

- `aboriginal/` — lesson photos
- `stickers/` — cat illustrations (PNG + SVG)
- `fonts/` — Bowlby One SC + Quicksand, self-hosted
- `slides/deck-stage.js` — the slide-deck engine
- `*.css` — Playful Detective tokens and lesson skins (`lesson30.css` is this lesson's theme)
